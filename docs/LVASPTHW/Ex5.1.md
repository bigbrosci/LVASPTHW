# Ex5.1 p4vasp 简介

前面四章，你已经会准备输入文件、批量改参数、批量提交、批量收结果了。但有一个问题一直没解决：你做的那个结构，你自己看过吗？POSCAR 里那几行数字，在你眼里是坐标，在电脑眼里也是坐标，可在你脑子里它应该是个模型。原子放在哪、吸附分子歪没歪，只看数字是看不出来的，结构怎么搭建？用什么软件？ 在AI横行霸道的今天，我们的选择太多了。但是在本教程里面，我还是给大家推荐p4vasp。 

## p4vasp 是什么

p4vasp 是 VASP 的可视化工具，也是我最爱的模型编辑器。可以通过命令行快读打开一个 POSCAR 或者 CONTCAR，就能看到体系长什么样，转一转、量一量键长，确认你建的模型是不是你脑子里想的那个模型。 在模型搭建的时候，操作也非常的简单，可以帮助我们快速搭建具有合理物理化学意义的结构，从而加快计算的过程。p4vasp 也可以帮我们分析一些计算过程的能量或者力的收敛情况，分析太密度，可视化动力学的的轨迹等等。功能还算强大。 

## p4vasp 的历史

p4vasp 不是新东西。原版是 Orest Dubay 在 2003、2004 年写的，官网是 p4vasp.at，是 VASP 圈子里用了很多年的老牌可视化工具。

它有个致命的问题：它是 Python2 写的。Python2 一退役，它就没人维护了，依赖的库一个接一个被时代淘汰，新电脑上根本装不上，官网后来也下线了。那段时间，想用 p4vasp 只有一个办法：找一台老 Ubuntu 18，用 apt 装那个老版本。

然后就是重生：我和 Whitehare2023 一起，把它从 Python2 搬到了 Python3，新版本叫 p4vasp-py3，代码放在 GitHub 上（https://github.com/bigbrosci/p4vasp/tree/p4vasp-py3）。现在这个新版本由我继续维护和开发，新内容的版权是 2026 年的 Bigbrosci，按 GPL 开源，原作者的版权说明保留。

一句话总结这段历史：p4vasp 死过一次，是因为 Python2 死了；现在它活过来了，而且功能更加强大。

## 为什么用 p4vasp

前面也说了，这个时代不缺工具，建模、可视化、后处理的软件一抓一大把，每个人的操作喜好还不一样。但这本书还是推荐 p4vasp，原因只有一个：它是教练车。为了达成让大家对计算建模，快速掌握关键的计算信息。本人觉得p4vasp是一款非常理想的教练车。等你学会建模中的各个细节，拿到驾照，再换豪华车、换自动驾驶的车，都是顺手的事。
